# Сад ума, прототип 0.0.2

Приложение для дневника состояний и буддийской практики на Android.
Главный экран украшает интерактивный пиксельный сад. Он отражает записанные состояния,
намерения, поступки и практики. Он меняется со временем, сохраняя красоту.
Здесь нет серий дней, штрафов за отсутствие и измерения «реальной кармы».

## Что это за сборка

Это исходный проект Godot, который можно открыть и запустить на компьютере.
Вертикальный интерфейс полностью пересобран. Три новых пиксельных фона и спрайты
созданы встроенным генератором изображений в общем холодном вечернем оформлении.
Окончательное попадание в авторский стиль канала ещё требует оценки пользователя.
Звук чаши синтезирован.

APK в архив не входит. Android-сборка и проверка на телефоне остаются
следующим этапом. Не раздавайте эту версию как готовое приложение.

## Запуск, без знания программирования

1. Установите стандартный Godot 4.7.2, не вариант .NET:
   https://godotengine.org/download/
2. Распакуйте архив в обычную папку на компьютере.
3. Откройте Godot, выберите «Импортировать» и файл `project.godot`.
4. Дождитесь импорта ресурсов и нажмите F5 или кнопку запуска сверху.
5. Стрелки по бокам переключают соседние экраны. Основная кнопка внизу открывает
   запись, дневник или практику. Меню «···» содержит историю и настройки.
6. Нажатие на сад перемещает персонажа только визуально. Ходить к предметам
   для использования функций приложения не требуется.

32 ГБ памяти для такого проекта достаточно. Отдельная видеокарта не требуется
для сложных вычислений: проект использует простой 2D-рендер.

## Что можно проверить

- Три места: стол записей, сад с прудом, навес с подушкой и поющей чашей.
- Один главный экран с большой иллюстрацией и минимумом элементов управления.
- Переключение соседних экранов боковыми стрелками.
- Нижние панели для записи и таймера, с прокруткой длинного содержимого.
- Движение персонажа и поглаживание кота как необязательные визуальные реакции.
- Причины изменений сада доступны из меню «···».
- Несколько эмоций в одной записи, интенсивность, свободный текст.
- Отмеченные дела оставляют ростки, пока есть свободные места.
- История с изменением текста и удалением ошибочных записей.
- Медитация на 1, 3, 5, 7 минут или без обратного отсчёта.
- Три звука в начале, один в конце, пауза и досрочное завершение.
- Пауза при уходе приложения в фон или потере фокуса.
- Примятость подушки после сохранённой практики.
- Смена света в зависимости от времени на устройстве.
- Временный дождь, облачность или ветер после некоторых отметок состояния.
- Рост, цветение, семена и новые циклы растений по прошедшему времени.
- Простое зарастание, без удаления растений за отсутствие.
- Сохранение с резервной копией и восстановлением при повреждении файла.

## Чего пока нет

- Установочного APK, проверки сенсорного управления и звука на телефоне.
- Готового экспорта/импорта сохранения, шифрования и биометрии.
- Отдельных практик метта, ходьбы, медитации лёжа и научно выверенного каталога.
- Будды с диалогами, свободного ИИ, голоса, облака и мультиплеера.
- Напоминаний, музыки, дождевого аудио и вибрации.
- Перетаскивания предметов, сложного поведения животных и полноценной экосистемы.
- Окончательного авторского оформления, согласованного набора анимаций и полировки.

Растения занимают 12 фиксированных мест. После заполнения записи продолжают
сохраняться; новые визуальные слои для наполненного сада пока не реализованы.
Интенсивность сохраняется в записи, но пока не меняет силу погодного эффекта.
Погода от состояния держится до шести часов, приоритет: грусть, затем тревога
или злость, затем усталость или неопределённость. Это временные, открытые правила.

## Где хранится сад

Godot сохраняет `garden.json` в своей пользовательской папке приложения.
Её можно открыть из редактора: Project → Open User Data Folder.
Файл `garden.json.bak` является предыдущей читаемой копией.
Файл `garden.json.unreadable`, если появился, сохраняет повреждённый оригинал.

Дневник сейчас хранится открытым текстом. Не вносите чувствительные записи
в общий компьютер. Это предупреждение об уже существующем ограничении,
а не обещание будущего шифрования.

Перед переносом или удалением приложения скопируйте `garden.json` в безопасное
место. До первой раздачи друзьям необходимо сделать удобный экспорт/импорт.

## Проверки

В терминале, из папки проекта:

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script res://tests/test_state.gd
godot --headless --path . -- --smoke
```

Замените `godot` на путь к установленному исполняемому файлу при необходимости.
Первый запуск импортирует ресурсы. Второй проверяет состояние мира и сохранения.
Третий выполняет короткий сценарий с интерфейсом, дневником и таймером.
Тестовый сценарий использует отдельное сохранение `smoke_garden.json`.

## Android, следующий шаг

Официальная инструкция:
https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html

Потребуются шаблоны экспорта, OpenJDK и Android SDK. Android Studio удобна
для установки SDK и диагностики. Основной игровой редактор остаётся Godot.
Подготовку APK следует провести на компьютере с установленным SDK и проверить
на физическом устройстве. Подпись обновлений нужно сохранять неизменной.

## Карта исходников

| Файл | Назначение |
|---|---|
| `scripts/garden_state.gd` | Записи, время, растения, погода, сохранение |
| `scripts/garden_view.gd` | Отрисовка сада, движение, нажатия |
| `scripts/main.gd` | Интерфейс, медитация, переходы, история |
| `tests/test_state.gd` | Проверки логики и восстановления |
| `tools/make_assets.py` | Воспроизводимый атлас растений и синтетический звук |
| `assets/ART-DIRECTION.md` | Направление оформления и тексты запросов к генератору |
| `DESIGN.md` | Принятые решения и ближайшие этапы |
| `AGENTS.md` | Правила следующих изменений с Codex |

Для запуска приложения Python не требуется. Он нужен только при пересоздании атласа
растений и синтетического звука; генератор использует Pillow. Шрифт DejaVu распространяется с отдельной
лицензией в `assets/FONT-LICENSE.txt`.
