# Решения

## 2026-10-26: переход к Android после обсуждения

Автор изменил прежнее решение отложить APK. Порядок: согласовать конкретный функционал, его цель и конечный результат; затем реализовать недостающее и собрать APK.

Подтверждено автором:

- Телефон: Nothing Phone (3a) Pro, Android 16, Nothing OS 4.1.
- Первый APK проверяется с открытым экраном.
- Ближайшая версия включает таймер и короткие практики с проверенными источниками.
- Первый APK использует тестовые записи; экспорт/импорт дневника до него не нужен.
- Репозиторий: https://github.com/sonechkammr/vibesvibesvibes.
- В GitHub должны быть исходники, README, заметки и история коммитов.
- При представлении нового этапа нужен вопрос, связывающий предложение с конечной целью.

В следующем ответе автор согласовал и поручил реализовать:

- Две карточки: внимание к дыханию и доброжелательность, тексты в PRACTICES.md.
- Сценарий: прочитать инструкцию, выбрать время и начать; сохранить обычный таймер.
- Собрать тестовый APK и опубликовать исходники и APK на GitHub.

Реализация 0.0.5 использует начальные 3 минуты для карточек; время меняется существующим колесом. Формат сохранения 2 не изменён, название практики записывается в существующее поле текста события.

Техническая организация: постоянная папка mind-garden/ для текущей версии, прежний каталог 0.0.2 сохраняется. Версии отражаются коммитами и впоследствии релизами. История до импорта 0.0.4 не выдумывается: локальная копия пришла без Git.
