- Две офлайн-практики: внимание к дыханию и доброжелательность. В карточках указаны сутта, переводчик и ссылка; русский текст обозначен как адаптация.

## Проверено

- Godot 4.7.2 stable, Windows; официальный экспортный шаблон той же версии.
- Импорт без ошибок и предупреждений GDScript.
- 50 проверок состояния/сохранения/миграций, 15 часов, 69 навигации/света.
- UI smoke: обе инструкции, переход к выбору времени и назад, отсутствие результата при чтении, название практики в истории, обычный свободный таймер, пауза, однократное завершение, загрузка и выключение звука.
- Графический прогон: обе карточки, меню и выбор времени. [Снимки](../../previews/practices/).
- Smoke на экспортированных ресурсах, извлечённых из финального APK, пройден тем же движком на Windows. Это проверка комплектности ресурсов и экспортированного GDScript; Android runtime этим не проверяется.
- Подпись APK v2/v3: подтверждена `apksigner`.
- `zipalign -c -P 16 -v 4`: пройден. Все LOAD-сегменты обеих ARM64-библиотек имеют выравнивание 16 384 байта.
- Manifest: пакет `org.sonechkammr.mindgarden`, version code 5, min SDK 24, target SDK 36, только ARM64. Разрешений Android нет.
- В APK нет дневников, ключей, документации, тестов, previews и локальных инструментов. Лицензии Godot и Manrope включены.
- Формат сохранений 2 не изменён.

Известная особенность инструмента: `aapt2 dump badging` предупреждает о неиспользуемом ресурсе `mipmap/themed_icon`, XML которого нативный экспорт Godot использует для основного `icon.xml`. Основной adaptive icon присутствует. Финальные журналы Godot не содержат ошибок; подпись, выравнивание и smoke ресурсов проходят. Предупреждение записано отдельно, а не принято за ошибку GDScript или скрыто.

## Установка и ограничения

На Nothing Phone скачайте APK и откройте его. При запросе Android разрешите установку из выбранного источника. После установки откройте «Сад ума».

Первый запуск проверяется с открытым экраном и тестовыми записями. На физическом Nothing Phone APK ещё не запускался; телефон не подключён к ADB. Сенсорный ввод, клавиатура, вырез, системные жесты и реальный звук требуют проверки на устройстве.

Гарантированный сигнал при блокировке и восстановление активной практики после уничтожения процесса отсутствуют. Экспорт/импорт реального дневника пока отсутствует. Debug-ключ хранится локально вне Git и нужен для следующих обновлений этой установки. Эта версия предназначена для личного теста перед раздачей друзьям.

Сценарии проверки телефона и повторная сборка: [ANDROID.md](../ANDROID.md).
