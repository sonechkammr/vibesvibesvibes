# Структура и публикация

Репозиторий: [sonechkammr/vibesvibesvibes](https://github.com/sonechkammr/vibesvibesvibes). Он публичный. Публикуется проектная работа: код, ресурсы, документация, результаты проверок и история решений.

```text
README.md                       навигатор репозитория
mind-garden/                    текущий проект
  project.godot                 точка входа Godot
  main.tscn                     основная сцена
  scripts/                      модель, отображение и интерфейс
  assets/                       графика, звук, шрифт и лицензия
  tests/                        автоматические проверки
  tools/                        проверка журналов и сборка APK
  previews/                     демонстрационные снимки и видео
  docs/                         решения, практики, Android, история
  README.md                     запуск и возможности
  EXEC_PLAN_MIND_GARDEN_0.0.4.md  текущий план до первого APK
  DESIGN.md                     продуктовые ограничения
  VERIFIED.md                   фактические проверки
  CHANGELOG.md                  изменения
mind-garden-prototype-0.0.2/     прежний прототип
```

Рабочую версию развивать в постоянной папке. Старую историю сохранять. Новый коммит описывает законченное изменение, например карточки практик, настройку экспорта или исправление Android-клавиатуры. Нельзя задним числом изображать несохранившуюся историю разработки 0.0.3–0.0.4 отдельными вымышленными коммитами.

В публикацию не включать `garden.json`, резервные копии дневника, ключи подписи, токены, `.env`, `.godot/`, `.local/`, установленные инструменты и логи с пользовательскими данными. `.gitignore` является дополнительной защитой; перед коммитом просматривать состав файлов и содержимое изменений.

Демонстрационные ресурсы можно хранить в Git. APK публикуется как отдельный артефакт релиза вместе с контрольной суммой, commit SHA и ограничениями. Первый тестовый релиз: `mind-garden-v0.0.5-android-test`. Отчёт: `docs/releases/0.0.5-android-test.md`.

Для текущей локальной сессии клонированный репозиторий находится в `.local/github/`. Основная папка редактирования пока является распакованным исходником; при публикации переносить в checkout только перечисленные проектные файлы, не весь каталог. В дальнейшем удобно работать непосредственно в клоне.
