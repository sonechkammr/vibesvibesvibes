# Первый Android APK 0.0.5

26 октября 2026 года. Подписанный тестовый APK собран для ARM64 / Android 16. Запуск на физическом телефоне ещё не проверен. Исходники и артефакты находятся в [GitHub-релизе](https://github.com/sonechkammr/vibesvibesvibes/releases/tag/mind-garden-v0.0.5-android-test).

## Установка на Nothing Phone

1. На телефоне откройте релиз и скачайте `mind-garden-0.0.5-android-arm64.apk` из Assets.
2. Откройте скачанный файл. Если Android запросит разрешение устанавливать приложения из этого источника, разрешите его выбранному браузеру или файловому приложению.
3. Установите и откройте «Сад ума». Для первой проверки используйте тестовые записи и открытый экран.
4. Проверьте запись, обе карточки, короткий таймер и повторное открытие приложения. Передайте замечания вместе с версией 0.0.5.

Прямая загрузка: [APK](https://github.com/sonechkammr/vibesvibesvibes/releases/download/mind-garden-v0.0.5-android-test/mind-garden-0.0.5-android-arm64.apk). Контрольная сумма доступна рядом в `SHA256SUMS.txt`.

Не удаляйте установленное приложение ради обновления, если в нём появились нужные записи. Для обновлений тестовой версии требуется тот же локальный debug-ключ; он сохранён вне Git. Перенос реального дневника через интерфейс пока отсутствует.

## Параметры сборки

- Godot 4.7.2.stable.official.ed1daf0bf, официальные шаблоны той же версии.
- JDK Temurin 17.0.20.1+1; Android Build Tools 36.0.0; target SDK 36, min SDK 24.
- Пакет `org.sonechkammr.mindgarden`, версия 0.0.5, version code 5, только `arm64-v8a`.
- Debug-подпись v2/v3. Разрешений Android нет. Системный backup данных выключен.
- Портретный экран, OpenGL Compatibility, экран поддерживается включённым во время работы приложения.
- Формат сохранений 2. Сетевых вызовов приложения нет; ссылка источника открывает внешний браузер только по нажатию.

## Повторная сборка

Установите Godot 4.7.2 и Android export templates той же версии. Настройте JDK, SDK и debug keystore в Editor Settings по [официальной инструкции](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html). Для этой сборки использованы SDK Platform 36, Build Tools 36.0.0 и platform-tools. Gradle, NDK и CMake не используются при экспорте готового нативного шаблона.

Из каталога проекта в PowerShell:

```powershell
./tools/build_android.ps1 -Godot 'C:/path/to/Godot_console.exe'
```

Скрипт запускает импорт, тесты, UI smoke и экспорт preset `Android test` в `builds/android/`. Затем проверьте `apksigner verify`, `zipalign -c -P 16 -v 4`, manifest, состав APK и SHA-256. Абсолютные локальные пути и ключи в Git не входят.

Выбор `all_resources` обязателен: экспорт только выбранной сцены в проверенной конфигурации пропускал зависимости GDScript. Документы, тесты, previews, локальные инструменты и данные исключены из APK. Лицензии Godot и Manrope включены.

## Ограничения

Первый APK рассчитан на открытый экран и тестовые записи. Надёжного аудио при блокировке и восстановления активной практики после уничтожения процесса нет. Экспорт/импорт и защита реального дневника остаются отдельными задачами перед раздачей друзьям.

При чтении таблицы ресурсов `aapt2` сообщает о неиспользуемом имени `mipmap/themed_icon`, чей XML нативный экспорт Godot заменяет основным `icon.xml`. Это особенность шаблона; основной adaptive icon присутствует, подпись и выравнивание проходят. Ошибок GDScript, загрузки ресурсов и предупреждений в финальном журнале Godot нет. Полный отчёт в releases/0.0.5-android-test.md.
