# Первый Android APK

Статус на 26 октября 2026 года: функционал обсуждается. APK не собран и на телефоне не проверен.

`project.godot` является описанием проекта. Для APK нужны также сцены, GDScript, ресурсы, шаблон экспорта и Android-инструменты. Переименование одного файла не создаёт приложение.

## Условия первой версии

- Nothing Phone (3a) Pro, Android 16, Nothing OS 4.1.
- Портретный экран, ARM64, личная debug-сборка.
- Открытый экран и тестовые записи.
- Дневник, сад, существующий таймер и согласованные короткие практики.
- Нет обещания фонового сигнала или восстановления активной сессии после закрытия процесса.

## Подготовка после согласования

1. Проверить установленный Godot и шаблоны той же версии. Текущий исходник проверен на Godot 4.7.2 stable.
2. Проверить JDK и Android SDK по [официальной инструкции Godot](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html). Документация рекомендует JDK 17. Точные версии SDK сверить с используемым движком при настройке.
3. Создать `export_presets.cfg`: фиксированный package ID, возрастающий version code, ARM64, портретная ориентация. Проверить разрешения, не добавлять сеть и датчики без необходимости.
4. Хранить debug keystore и локальные пути вне репозитория. Сохранить тот же ключ для обновления тестовой установки. Подпись не публиковать как отдельный секретный файл.
5. Исключить `docs/`, `previews/`, `tests/`, `.local/`, журналы и личные данные из пакета. Проверить содержимое фактического APK.
6. Повторить импорт, тесты и UI smoke; экспортировать в `builds/android/`. Проверить подпись и SHA-256. Записать commit SHA.

Проверка окружения в этой сессии: движок 4.7.2 найден; preset отсутствует; установленные Android export templates не обнаружены в стандартном каталоге. JDK/SDK не найдены в проверенных стандартных местах и командах. Это не доказывает отсутствие нестандартной установки; установка инструментов ещё не проводилась.
