# Vibes: проекты

## Сад ума

Офлайн-приложение на Godot для дневника состояний и буддийской практики с интерактивным садом. Целевая платформа: Android.

**Текущая версия: 0.0.5.** Добавлены две короткие практики с источниками, обычный таймер сохранён. Подписанный тестовый ARM64 APK собран и проверен; запуск на физическом телефоне ещё предстоит. Первый тест проводится с открытым экраном и тестовыми записями.

**[Скачать APK для Android](https://github.com/sonechkammr/vibesvibesvibes/releases/download/mind-garden-v0.0.5-android-test/mind-garden-0.0.5-android-arm64.apk)** · [релиз и контрольная сумма](https://github.com/sonechkammr/vibesvibesvibes/releases/tag/mind-garden-v0.0.5-android-test).

Для запуска откройте `mind-garden/project.godot` в Godot 4.7.2 и нажмите F5.

Существующий [прототип 0.0.2](mind-garden-prototype-0.0.2/) сохранён для истории. Текущая работа находится в постоянной папке `mind-garden/`.

В репозитории находятся исходники и демонстрационные материалы. Личные дневники, ключи подписи, токены и локальные инструменты не публикуются.
