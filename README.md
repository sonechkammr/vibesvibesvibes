# Vibes: проекты

## Сад ума

Офлайн-приложение на Godot для дневника состояний и буддийской практики с интерактивным садом. Целевая платформа: Android.

**Текущая версия исходников: 0.0.4.** Сейчас согласуется функционал перед первым тестовым APK. APK пока не собран. Первый тест на телефоне планируется с открытым экраном и тестовыми записями.

Для запуска откройте `mind-garden/project.godot` в Godot 4.7.2 и нажмите F5.

Существующий [прототип 0.0.2](mind-garden-prototype-0.0.2/) сохранён для истории. Текущая работа находится в постоянной папке `mind-garden/`.

В репозитории находятся исходники и демонстрационные материалы. Личные дневники, ключи подписи, токены и локальные инструменты не публикуются.
